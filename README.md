## Install or update

1. Download `app.apk` on your Android TV device (Android 8.0 or newer).
2. Allow your chosen downloader to install apps if Android asks.
3. Install the APK. Choose **Done** to keep your current screen, or **Open** to start setup.
4. Add your own sources. No channels, accounts or playlists are included.

To update an existing compatible installation, download the same link again and install over it. Do not uninstall first if you want to retain your settings.

These are development-signed test builds. Choose System, Deutsch or English in Settings > General > App language. Settings > About > App updates provides explicit update checks. Optional daily checks do not download or install automatically; download and Android installation require your choice. Read the release notes for known limits. The reported setup failure remains under investigation; remaining seek and VPN/SD/UHD checks are deferred.

## Files

- `app.apk`: Android TV application.
- `release.json`: version, checksum and signing-certificate fingerprint.
- `SHA256SUMS.txt`: download integrity checksums.
- `audio-dependency-sources.zip`: corresponding open-source audio dependency sources, licenses and relinking inputs.

Application source and tester feedback are managed separately. Downloading this APK does not require a GitHub account.
